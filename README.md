# Sori

Free, unlimited voice typing for Mac and Windows. Hold a key, talk, let go, and Sori types it into any app.
Your voice never leaves your computer.

**Website and downloads: https://yolee222.github.io/sori-app/**

- Mac (Apple Silicon): [Sori-mac.dmg](https://github.com/yolee222/sori-app/releases/latest/download/Sori-mac.dmg)
- Windows 10/11: [Sori-Windows-Setup.exe](https://github.com/yolee222/sori-app/releases/latest/download/Sori-Windows-Setup.exe)

This repository holds the website and the installers. Sori by KJ_AIS.
